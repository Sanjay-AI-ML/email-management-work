# Maildesk project presentation

- `Maildesk_Email_Management_System.pptx`: original editable 10-slide presentation.
- `Maildesk_10_Image_Slides.pptx`: 10 generated slide images, one image per slide.
- `Maildesk_10_Slide_Images.zip`: the individual PNGs and their generation prompts.
- `generated-images/`: source PNGs and the original prompt manifest.

The slides describe the project at the earlier integration milestone. Test counts
and setup status in those exported images are historical; consult the root README
and `INTEGRATION.md` for the final combined code and current verification results.
Image-slide text is embedded in each image; use the original deck for editable text.
